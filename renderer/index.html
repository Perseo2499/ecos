group

Cada persona debe usar su propio usuario de WordPress y su propia contraseña de aplicación.

Así cada entrada queda a nombre de quien la escribe. Se crea en Usuarios → Perfil → Contraseñas de aplicación.

key¿Cómo creo la contraseña de aplicación?
  1. Entra en tu web/wp-admin con tu usuario.
  2. Usuarios → Perfil → baja hasta «Contraseñas de aplicación».
  3. Escribe «Ecos» como nombre y pulsa «Añadir nueva contraseña de aplicación».
  4. Copia la contraseña que aparece (solo se muestra una vez) y pégala aquí.
info¿Cómo se configura?

Crea una app tipo «Web» en developer.wordpress.com/apps y pega la Redirect URL de arriba.

photo_library

Google Fotos

Fotos para entradas y páginas
info¿Cómo lo consigo?
  1. Entra en console.cloud.google.com con tu cuenta de Google y crea un proyecto nuevo (por ejemplo «Ecos»).
  2. Menú «APIs y servicios» → Biblioteca → busca «Google Photos Picker API» y pulsa «Habilitar».
  3. Pantalla de consentimiento (Google Auth Platform): tipo «Externo». Después, en «Público» (Audience) → «Usuarios de prueba», pulsa «Añadir usuarios» y escribe tu correo de Google. Si no lo haces, Google muestra «Acceso bloqueado: Ecos no ha completado el proceso de verificación» (error 403 access_denied).
  4. Credenciales → Crear credenciales → ID de cliente de OAuth → tipo de aplicación «Aplicación de escritorio». Copia el ID de cliente y el secreto y pégalos aquí.
  5. Pulsa «Conectar con Google», elige tu cuenta y acepta el permiso.

Aviso: mientras la app de Google esté en modo «Prueba», Google caduca el permiso a los 7 días y habrá que volver a pulsar «Conectar con Google». Para evitarlo, en la pantalla de consentimiento pulsa «Publicar aplicación» (no hace falta verificarla si solo la usas tú).

Ecos no puede ver toda tu biblioteca: solo recibe las fotos que elijas en la ventana de Google Fotos.

backup

Copia de seguridad

cloud_downloadCopia de seguridad de la web

Descarga todas las entradas y páginas de tu web (texto, categorías, etiquetas, fechas e imagen destacada) en un archivo XML de WordPress. Sirve para restaurarlas con Ecos o importarlas en cualquier WordPress.

emergency_homeCopia de emergencia

Un solo ZIP con todo lo necesario para volver a levantar la web si se pierde: el contenido y las fotos, una copia navegable de cómo se ve ahora (se abre sin internet), la configuración (menús, ajustes y personalizador de Astra, CSS adicional, plugins y temas con su versión) y una guía de recuperación paso a paso.

folder

Puede ser una carpeta de Google Drive (o de otro servicio en la nube) para que la copia quede también fuera de este ordenador.

Las copias automáticas se hacen al abrir Ecos, si toca, en segundo plano y con pausas para no cargar tu web.
