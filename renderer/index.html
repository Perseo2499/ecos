key¿Cómo creo la contraseña de aplicación?
  1. Entra en tu web/wp-admin con tu usuario.
  2. Usuarios → Perfil → baja hasta «Contraseñas de aplicación».
  3. Escribe «Ecos» como nombre y pulsa «Añadir nueva contraseña de aplicación».
  4. Copia la contraseña que aparece (solo se muestra una vez) y pégala aquí.
info¿Cómo se configura?

Crea una app tipo «Web» en developer.wordpress.com/apps y pega la Redirect URL de arriba.

info¿Cómo funciona?

La terminal se abre en la carpeta del código de Ecos. Desde ahí, Claude Code puede leer y modificar la app. Para probar los cambios, escribe «npm start» (ejecuta la versión de desarrollo) y, cuando estén listos, súbelos a GitHub: se publicará una actualización automática.
